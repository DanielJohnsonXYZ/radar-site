# Radar

Radar is an always-on account manager for agencies and freelancers. It reads client emails, meetings and Slack, then tells you who might leave, who might buy more, and what you promised but haven’t done.

This is the public marketing site and a fictional product demo.

## Run locally

```bash
npm install
npm run dev
```

The app listens on [http://127.0.0.1:43147](http://127.0.0.1:43147).

```bash
npm run build
npm start -- --port 43147
```

## What’s in here

- Homepage, founding-pilot form, and a read-only demo (Today, Clients, Commitments, Integrations)
- Privacy and security notes

Every client, contact and number in the demo is invented.
